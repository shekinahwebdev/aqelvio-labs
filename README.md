## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

Set `NEXT_PUBLIC_SITE_URL` in `.env.local` for production metadata and sitemap URLs (see `.env.example`).
